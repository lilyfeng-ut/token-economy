# Token Economy Architecture

A dependency-free interactive architecture page for designing an AI token economy. It covers request admission, context engineering, semantic caching, model routing, execution, verification, and closed-loop economics.

## Preview locally

Open `Token-Economy/index.html` directly, or serve the repository root with any static file server.

## Publish with GitHub Pages

1. Push this repository to GitHub with `main` as the default branch.
2. In **Settings → Pages → Build and deployment**, select **GitHub Actions**.
3. Run the included **Deploy Token Economy to GitHub Pages** workflow (or push to `main`).

The workflow publishes the contents of `Token-Economy/` as the site root. No build command or dependencies are required.

## Files

- `Token-Economy/index.html` — home page and AI systems architecture introduction
- `Token-Economy/architecture.html` — interactive request simulation
- `Token-Economy/methods.html` — implementation design briefs
- `Token-Economy/decisions.html` — ordered optimization method
- `Token-Economy/assets/site.css` — shared visual system
- `Token-Economy/assets/site.js` — shared interactions
- `Token-Economy/assets/token-economy-social.png` — social preview artwork
- `.github/workflows/pages.yml` — GitHub Pages deployment
